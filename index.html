      How I build

      Find the broken workflow. Spec it. Ship it, then keep shipping.

      01 / DISCOVER

      Start where the work breaks.

      Talk to the people doing the job, map the current workflow, and write down exactly what slows them down.

      Users before code.
      02 / SPEC & BUILD

      Give the idea a spec to stand on.

      Turn findings into a PRD and roadmap, design the data model and APIs, and build the smallest version worth shipping.

      PRD → MVP
      03 / SHIP & ITERATE

      Ship it. Then make it better.

      Deploy early, add audit logs and analytics, gather feedback, and improve sprint by sprint.
